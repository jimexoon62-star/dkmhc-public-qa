# الاختبارات العامة المنفصلة

دي حزمة اختبار **اصطناعية بالكامل**، ما نسخة من موقع العيادة، وما عندها اتصال بقاعدة بيانات أو تقويم أو واتساب أو حسابات الدفع.

## الهدف
- إتاحة فحوص منطقية بسيطة يمكن تشغيلها داخل مستودع GitHub عام باستخدام المشغّلات القياسية.
- إثبات قاعدة: لا موعد معتمد قبل التحقق البشري من الدفع والموافقة وتوفر الخانة.
- إثبات قاعدة: صورة التحويل أو تصريح الشخص بالدفع لا تكفي لاعتماد الدفع.
- إثبات قاعدة: الرسائل ذات المحتوى السريري أو الخطر تُحال للبشر بلا رد آلي.

## حدود النتيجة
نجاح الفحوص هنا **لا** يعني نجاح نظام العيادة الحقيقي ولا يسمح بالنشر للإنتاج.

## رفع الملفات
أنشئ مستودعاً عاماً **جديداً وفارغاً**. لا تنسخ مستودع العيادة الخاص، ولا تستخدم Fork أو Template له. ارفع ملفات هذه الحزمة فقط بجذر المستودع مع الحفاظ على المجلدات. لا ترفع ملف ZIP داخل المستودع بدلاً من فكّه.

## منع التسريب
لا مفاتيح API، لا أسماء مرضى، لا أرقام هواتف، لا إشعارات دفع حقيقية، لا ملف إعدادات إنتاج، ولا تاريخ Git الخاص. الاختبارات تستخدم بيانات تخيلية فقط.
